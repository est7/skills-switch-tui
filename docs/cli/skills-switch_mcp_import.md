## skills-switch mcp import

Add MCP servers from a pasted JSON definition

```
skills-switch mcp import [json] [flags]
```

### Options

```
      --file string   read the JSON definition from a file
  -h, --help          help for import
      --json          emit JSON
      --name string   server name for a bare (unkeyed) object
```
