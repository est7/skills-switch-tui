## skills-switch skills enable

Enable a skill or source in one projection scope

```
skills-switch skills enable [skill-id] [flags]
```

### Options

```
      --client strings   registered target client (repeatable)
  -h, --help             help for enable
      --json             emit JSON
      --scope string     projection scope: project or global (default "project")
      --source string    operate on every compatible skill in a source
```
