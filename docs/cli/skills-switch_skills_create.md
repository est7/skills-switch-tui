## skills-switch skills create

Scaffold a new local Skill skeleton

```
skills-switch skills create <name> [flags]
```

### Options

```
      --description string   Skill description for the frontmatter
      --group string         group directory (default: a standalone group named after the Skill)
  -h, --help                 help for create
      --json                 emit JSON
      --scope string         local scope (shared or a registered client id) (default "shared")
```
